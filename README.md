# Prism

Camera hand tracking, floating islands, weather and visual effects.

## Download

[Download source ZIP](https://github.com/eire360/prism/archive/refs/heads/main.zip)

## Setup

Requires an Apple Silicon Mac with macOS 14 or later, a camera, and Apple developer command-line tools.

```sh
./build.sh
open "build/Prism.app"
```

Click Start camera and allow camera access when macOS asks. Camera frames are processed locally.

## Controls

Pinch to pick up an island. Use two hands to resize and rotate it. Release to leave it floating.
