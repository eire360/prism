# Prism

Camera hand tracking, floating islands, weather and visual effects.

## Download

[Download source ZIP](https://github.com/eire360/prism/archive/refs/heads/main.zip)

## Setup

Requires macOS, a camera, and Apple developer tools. The Swift application source is in `Source/`. Grant camera access when you first start the camera.

The application uses SwiftUI, SceneKit, Vision, AVFoundation and Metal. A standalone installer is not included.

## Controls

Pinch to pick up an island. Use two hands to resize and rotate it. Release to leave it floating.
